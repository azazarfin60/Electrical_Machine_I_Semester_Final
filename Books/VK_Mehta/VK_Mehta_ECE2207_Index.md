## 3. Comprehensive Master Formula Cheatsheet

### 3.1 Transformers (Chapter 7)

1. **EMF Equation:**
   $$E_1 = 4.44 f N_1 \Phi_m, \quad E_2 = 4.44 f N_2 \Phi_m$$
   $$K = \frac{E_2}{E_1} = \frac{N_2}{N_1} = \frac{V_2}{V_1} = \frac{I_1}{I_2}$$

2. **No-Load Phasor Parameters:**
   $$I_w = I_0 \cos \phi_0, \quad I_m = I_0 \sin \phi_0, \quad I_0 = \sqrt{I_w^2 + I_m^2}$$
   $$R_0 = \frac{V_1}{I_w} = \frac{V_1^2}{W_0}, \quad X_0 = \frac{V_1}{I_m}, \quad W_0 = V_1 I_0 \cos \phi_0 = P_i$$

3. **Impedance Shifting Rules:**
   - From Primary to Secondary: multiply by $K^2$ ($R_1' = K^2 R_1$, $X_1' = K^2 X_1$).
   - From Secondary to Primary: divide by $K^2$ ($R_2' = R_2 / K^2$, $X_2' = X_2 / K^2$).
   - $R_{01} = R_1 + \frac{R_2}{K^2}, \quad X_{01} = X_1 + \frac{X_2}{K^2}, \quad Z_{01} = \sqrt{R_{01}^2 + X_{01}^2}$
   - $R_{02} = R_2 + K^2 R_1, \quad X_{02} = X_2 + K^2 X_1, \quad Z_{02} = K^2 Z_{01}$

4. **Voltage Regulation & Drop:**
   $$\Delta V_2 = I_2 R_{02} \cos \phi_2 \pm I_2 X_{02} \sin \phi_2 \quad (+ \text{ lagging}, - \text{ leading})$$
   $$\% VR = \frac{E_2 - V_2}{V_2} \times 100 \approx \frac{I_2 R_{02} \cos \phi_2 \pm I_2 X_{02} \sin \phi_2}{V_2} \times 100$$
   - Zero Regulation Condition: $\tan \phi_2 = \frac{R_{02}}{X_{02}}$ (leading p.f.)
   - Maximum Regulation Condition: $\tan \phi_2 = \frac{X_{02}}{R_{02}}$ (lagging p.f., $\cos \phi_2 = \frac{R_{02}}{Z_{02}}$)

5. **Efficiency & Maximum Efficiency:**
   $$\eta_x = \frac{x \cdot \text{kVA} \cdot 10^3 \cos \phi}{x \cdot \text{kVA} \cdot 10^3 \cos \phi + P_i + x^2 P_{c(FL)}} \times 100$$
   - Condition for $\eta_{max}$: $P_i = x^2 P_{c(FL)} \implies \mathbf{x = \sqrt{\frac{P_i}{P_{c(FL)}}}}$
   - $\text{kVA for } \eta_{max} = \text{Full Load kVA} \times \sqrt{\frac{P_i}{P_{c(FL)}}}$

6. **Autotransformer:**
   $$W_a = (1 - K) W_o, \quad \text{Saving of Copper} = K \times W_o$$
   $$\text{Inductive Power} = (1 - K) \times \text{Input}, \quad \text{Conducted Power} = K \times \text{Input}$$
   $$\text{kVA}_{\text{auto}} = \frac{\text{kVA}_{\text{2-wdg}}}{1 - K}$$

7. **Parallel Operation (Equal Ratio):**
   $$I_A = I \frac{Z_B}{Z_A + Z_B}, \quad I_B = I \frac{Z_A}{Z_A + Z_B}$$
   $$S_A = S \frac{Z_B}{Z_A + Z_B}, \quad S_B = S \frac{Z_A}{Z_A + Z_B}$$

8. **Three-Phase Open-Delta (V-V):**
   $$S_{V-V} = \sqrt{3} V_L I_L = \frac{1}{\sqrt{3}} S_{\Delta-\Delta} = 0.577 S_{\Delta-\Delta} = 86.6\% \times (2 \times \text{Rating})$$
   $$\text{p.f. of Transformer 1} = \cos(30^\circ - \phi), \quad \text{p.f. of Transformer 2} = \cos(30^\circ + \phi)$$

9. **Scott Connection (T-T):**
   - Teaser primary turns: $N_T = 0.866 N_1 = \frac{\sqrt{3}}{2} N_1$
   - Converts 3-phase to balanced 2-phase at identical secondary voltage $V_2 = V_L (N_2 / N_1)$ in $90^\circ$ quadrature.

### 3.2 Three-Phase Induction Motors (Chapter 8)

1. **Synchronous Speed & Slip:**
   $$N_s = \frac{120 f}{P}, \quad s = \frac{N_s - N}{N_s}, \quad N = N_s (1 - s)$$
   $$f' = s f, \quad E_2' = s E_2, \quad X_2' = s X_2, \quad Z_2' = \sqrt{R_2^2 + (s X_2)^2}$$

2. **Rotor Current & Power Factor:**
   $$I_2' = \frac{s E_2}{\sqrt{R_2^2 + (s X_2)^2}}, \quad \cos \theta_2' = \frac{R_2}{\sqrt{R_2^2 + (s X_2)^2}}$$

3. **Torque Equations:**
   - Starting Torque ($s = 1$):
     $$T_s = \frac{k E_2^2 R_2}{R_2^2 + X_2^2}$$
     Maximum Starting Torque occurs when: $\mathbf{R_2 = X_2}$
   - Running Torque at slip $s$:
     $$T = \frac{k \cdot s \cdot E_2^2 \cdot R_2}{R_2^2 + (s X_2)^2}$$
   - Maximum Running Torque ($T_{max}$):
     $$s_m = \frac{R_2}{X_2}, \quad \mathbf{T_{max} = \frac{k E_2^2}{2 X_2}} \quad (\text{independent of } R_2!)$$
   - Full-load to Maximum Torque ratio:
     $$\frac{T_{FL}}{T_{max}} = \frac{2 s_m s_f}{s_m^2 + s_f^2}$$
   - Starting to Maximum Torque ratio:
     $$\frac{T_s}{T_{max}} = \frac{2 s_m}{1 + s_m^2}$$

4. **Power Flow Ratio (The Golden Rule):**
   $$\mathbf{P_2 : P_{cu} : P_m = 1 : s : (1 - s)}$$
   - Rotor Input: $P_2 = T_g \times \omega_s = \frac{2\pi N_s}{60} T_g$
   - Rotor Copper Loss: $P_{cu} = 3 (I_2')^2 R_2 = s P_2$
   - Gross Mechanical Power: $P_m = (1 - s) P_2 = T_g \times \omega = \frac{2\pi N}{60} T_g$
   - Shaft Output: $P_{out} = P_m - P_{\text{friction\&windage}}$

5. **Mechanical Load Representation:**
   $$R_L' = R_2' \left(\frac{1 - s}{s}\right) = \frac{R_2'}{s} - R_2'$$

6. **Starting Methods & Torques:**
   - **DOL Starter:**
     $$\frac{T_{st}}{T_{FL}} = \left(\frac{I_{sc}}{I_{FL}}\right)^2 \times s_f$$
   - **Stator Resistor Starter (ratio $x$):**
     $$\frac{T_{st}}{T_{FL}} = x^2 \left(\frac{I_{sc}}{I_{FL}}\right)^2 \times s_f, \quad I_{st} = x I_{sc}$$
   - **Autotransformer Starter (tapping $x$):**
     $$\frac{T_{st}}{T_{FL}} = x^2 \left(\frac{I_{sc}}{I_{FL}}\right)^2 \times s_f, \quad I_{line} = x^2 I_{sc}$$
   - **Star-Delta Starter:**
     $$I_{st(Y)} = \frac{1}{3} I_{sc(\Delta)}, \quad T_{st(Y)} = \frac{1}{3} T_{st(\Delta)}$$
     $$\frac{T_{st}}{T_{FL}} = \frac{1}{3} \left(\frac{I_{sc}}{I_{FL}}\right)^2 \times s_f$$

### 3.3 Single-Phase Induction Motors (Chapter 9)

1. **Double-Field Revolving Theory:**
   $$\Phi(t) = \Phi_m \cos \omega t = \frac{\Phi_m}{2} e^{j\omega t} + \frac{\Phi_m}{2} e^{-j\omega t}$$
   - Forward slip: $s_f = s$
   - Backward slip: $s_b = \frac{N_s - (-N)}{N_s} = \frac{N_s + N}{N_s} = \mathbf{2 - s}$
   - Standstill ($s = 1$): $s_f = 1, s_b = 1 \implies T_f = T_b \implies T_{\text{start}} = 0$.

2. **Starting Torque from Phase-Splitting:**
   $$T_s \propto I_m I_s \sin \alpha$$
   (Maximum torque when $\alpha = 90^\circ$).

3. **Equivalent Circuit Impedances:**
   $$Z_f = R_f + j X_f = \frac{j \frac{X_m}{2} \left(\frac{R_2'}{2s} + j \frac{X_2'}{2}\right)}{\frac{R_2'}{2s} + j\left(\frac{X_m}{2} + \frac{X_2'}{2}\right)}$$
   $$Z_b = R_b + j X_b = \frac{j \frac{X_m}{2} \left(\frac{R_2'}{2(2-s)} + j \frac{X_2'}{2}\right)}{\frac{R_2'}{2(2-s)} + j\left(\frac{X_m}{2} + \frac{X_2'}{2}\right)}$$
   $$Z_{\text{total}} = (R_1 + j X_1) + Z_f + Z_b$$
   $$T_{\text{net}} = \frac{I_1^2 (R_f - R_b)}{\omega_s} \quad \text{N-m}$$
