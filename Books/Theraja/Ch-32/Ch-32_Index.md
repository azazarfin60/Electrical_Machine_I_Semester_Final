## ⚡ Master Formula Quick Reference

### 1. E.M.F. & Transformation
* **R.M.S. Induced E.M.F.:**
  $$E_1 = 4.44 f N_1 \Phi_m = 4.44 f N_1 B_{max} A$$
  $$E_2 = 4.44 f N_2 \Phi_m = 4.44 f N_2 B_{max} A$$
* **Transformation Ratio:**
  $$K = \frac{E_2}{E_1} = \frac{N_2}{N_1} = \frac{I_1}{I_2}$$

### 2. Equivalent Circuit Parameters
* **Referred to Primary:**
  $$R_{01} = R_1 + \frac{R_2}{K^2}, \quad X_{01} = X_1 + \frac{X_2}{K^2}, \quad Z_{01} = \sqrt{R_{01}^2 + X_{01}^2}$$
* **Referred to Secondary:**
  $$R_{02} = R_2 + K^2 R_1, \quad X_{02} = X_2 + K^2 X_1, \quad Z_{02} = \sqrt{R_{02}^2 + X_{02}^2}$$
* **Shunt Exciting Branch (from O.C. Test):**
  $$\cos \phi_0 = \frac{W_0}{V_1 I_0}, \quad I_w = I_0 \cos \phi_0, \quad I_\mu = I_0 \sin \phi_0$$
  $$R_0 = \frac{V_1}{I_w}, \quad X_0 = \frac{V_1}{I_\mu}, \quad G_0 = \frac{W_0}{V_1^2}, \quad B_0 = \sqrt{Y_0^2 - G_0^2}$$

### 3. Voltage Regulation
* **Approximate Expression:**
  $$\%\text{ Regulation} = \frac{I_2 (R_{02} \cos \phi \pm X_{02} \sin \phi)}{_0V_2} \times 100\% = v_r \cos \phi \pm v_x \sin \phi$$
  *( $+$ for lagging p.f., $-$ for leading p.f. )*
* **Condition for Zero Regulation (Leading p.f. only):**
  $$\tan \phi = \frac{R_{02}}{X_{02}} \implies \cos \phi = \frac{X_{02}}{\sqrt{R_{02}^2 + X_{02}^2}}$$
* **Condition for Maximum Regulation (Lagging p.f.):**
  $$\tan \phi = \frac{X_{02}}{R_{02}} \implies \cos \phi = \frac{R_{02}}{\sqrt{R_{02}^2 + X_{02}^2}}$$

### 4. Efficiency & Core Loss Separation
* **Commercial Efficiency:**
  $$\eta = \frac{x S_{FL} \cos \phi}{x S_{FL} \cos \phi + W_i + x^2 W_{cu(FL)}} \times 100\%$$
* **Condition for Maximum Efficiency:**
  $$W_i = x^2 W_{cu(FL)} \implies x = \sqrt{\frac{W_i}{W_{cu(FL)}}}$$
  $$\text{kVA at } \eta_{max} = \text{kVA}_{FL} \times \sqrt{\frac{W_i}{W_{cu(FL)}}}$$
* **Core Loss Separation:**
  $$\frac{W_i}{f} = A + B f \implies W_h = A f, \quad W_e = B f^2$$
* **All-Day Efficiency:**
  $$\eta_{\text{all-day}} = \frac{\sum (P_{out} \times t)}{\sum (P_{out} \times t) + (W_i \times 24) + \sum (W_{cu} \times t)} \times 100\%$$

### 5. Auto-Transformers
* **Copper Saving:**
  $$\frac{\text{Weight of Cu in Auto-transformer}}{\text{Weight of Cu in 2-winding transformer}} = 1 - K$$
  $$\text{Saving of Copper} = K \times W_0$$
* **Power Transfer Breakdown:**
  $$\text{Power transferred conductively} = K \times \text{Input Power}$$
  $$\text{Power transferred inductively} = (1 - K) \times \text{Input Power}$$
* **kVA Rating Expansion (Two-winding to Auto):**
  $$\text{kVA}_{\text{auto}} = \text{kVA}_{\text{2-w}} \times \frac{1}{1 - K} \quad \text{(Step-down)}$$

### 6. Parallel Operation
* **Equal Voltage Ratios ($E_A = E_B$):**
  $$I_A = I \left(\frac{Z_B}{Z_A + Z_B}
ight), \quad I_B = I \left(\frac{Z_A}{Z_A + Z_B}
ight)$$
  $$S_A = S \left(\frac{Z_B}{Z_A + Z_B}
ight), \quad S_B = S \left(\frac{Z_A}{Z_A + Z_B}
ight)$$
* **Unequal Voltage Ratios ($E_A \ne E_B$):**
  $$I_C = \frac{E_A - E_B}{Z_A + Z_B} \quad \text{(Circulating Current on No-Load)}$$
  $$I_A = \frac{E_A Z_B + (E_A - E_B) Z_L}{Z_A Z_B + Z_L(Z_A + Z_B)}$$
  $$I_B = \frac{E_B Z_A - (E_A - E_B) Z_L}{Z_A Z_B + Z_L(Z_A + Z_B)}$$
